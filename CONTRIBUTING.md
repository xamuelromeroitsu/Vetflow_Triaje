# Cómo colaborar

1. Lee [docs/07-gestion/metodologia.md](docs/07-gestion/metodologia.md) (estados, ramas, commits).
2. Toma una historia del [backlog](docs/02-requisitos/historias/indice.md) y crea una rama: `feature/us-01-registro-mascota`.
3. Si cambias una decisión, actualiza el documento afectado **en el mismo commit**.
4. Una decisión técnica importante se registra como ADR: [docs/plantillas/adr.md](docs/plantillas/adr.md).
5. Antes de pedir revisión, comprueba la [definición de "Hecho"](docs/06-calidad/definicion-de-hecho.md).

## Commits
`tipo(alcance): descripción` · tipos: `feat`, `fix`, `docs`, `test`, `refactor`, `chore`.

## Cambios clínicos
Cualquier cambio en reglas de triaje o rangos de signos vitales necesita revisión de un veterinario. Ver [validación veterinaria](docs/03-triaje-clinico/validacion-veterinaria.md).
