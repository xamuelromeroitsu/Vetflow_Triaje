# Usuarios y personas

> Son **hipótesis** basadas en el proyecto. Hay que validarlas con entrevistas a dueños y personal de la clínica piloto.

## Persona 1 · Dueño de mascota ("Marta")
| | |
|---|---|
| Contexto | Su perro vomita desde la mañana; es de noche y está nerviosa |
| Objetivo | Saber si debe ir ya a una clínica |
| Dolores | No sabe qué es grave; miedo a gastar de más o a llegar tarde |
| Habilidad técnica | Media; usa el móvil con una mano |
| Necesita | Pocas preguntas, lenguaje simple, resultado claro y qué hacer |

## Persona 2 · Recepción / enfermería ("Luis")
| | |
|---|---|
| Contexto | Sala de espera llena, teléfono sonando |
| Objetivo | Registrar rápido y que nadie grave quede esperando |
| Dolores | Datos incompletos, papeles, repetir preguntas |
| Necesita | Captura rápida de signos vitales y ver la cola |

## Persona 3 · Veterinario ("Dra. Andrea")
| | |
|---|---|
| Contexto | Atiende y a la vez decide a quién ver |
| Objetivo | Ver primero lo más grave, con datos útiles |
| Dolores | Información dispersa; no fiarse de una herramienta que "adivina" |
| Necesita | Ficha clara, poder corregir el nivel, ver por qué se sugirió |

## Persona 4 · Administrador de clínica ("Carlos")
| | |
|---|---|
| Contexto | Dueño o gerente de la clínica |
| Objetivo | Menos saturación, mejor servicio |
| Necesita | Gestionar personal y ver cómo va la operación (fases posteriores) |
