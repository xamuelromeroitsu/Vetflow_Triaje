# US-16 · Ver mis citas programadas

**Épica:** EPC-07 · **Prioridad:** Alta · **Fase:** 2

**Como** dueño de mascota, **quiero** ver el listado de mis citas veterinarias programadas, **para** conocer cuándo y dónde debo acudir con mi mascota.

## Criterios de aceptación
- [ ] Listar citas programadas del dueño con fecha, hora, clínica, veterinario y mascota.
- [ ] Mostrar estado de cada cita (programada, confirmada, en curso, completada, cancelada, reprogramada).
- [ ] Permitir cancelar una cita programada con antelación.
- [ ] Permitir reprogramar una cita eligiendo otro horario disponible.
- [ ] Mostrar mascota asociada a cada cita.

## Escenario
```
Dado que el dueño tiene citas programadas
Cuando abre la pantalla de mis citas
Entonces ve todas sus citas con fecha, hora, clínica y estado
```

## Fuera de alcance
- Historial clínico de atención realizada (pertenece a EPC-08).
- Consultar citas de otras mascotas que no sean del dueño autenticado.

## Preguntas pendientes
- ¿Cuánto tiempo se mantienen visibles las citas completadas/canceladas?
