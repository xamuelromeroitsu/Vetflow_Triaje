# Definiciones de "Listo" y "Hecho"

## Definición de "Listo" (para empezar una historia)
- [ ] Tiene formato Como / Quiero / Para.
- [ ] Criterios de aceptación claros y comprobables.
- [ ] Sin preguntas pendientes que bloqueen.
- [ ] Dividida en tareas pequeñas.
- [ ] Pantallas o bocetos disponibles si hay UI.

## Definición de "Hecho" (para cerrarla)
- [ ] Cumple todos los criterios de aceptación.
- [ ] Pruebas escritas y pasando (unitarias donde haya lógica).
- [ ] Probada en un dispositivo real.
- [ ] Maneja errores y falta de conexión.
- [ ] Reglas de seguridad actualizadas si toca datos.
- [ ] Documentación actualizada si cambió una decisión.
- [ ] Si toca triaje: revisada por un veterinario.
- [ ] Integrada en `main`.
